# サンプルの3Dハウス

ここに `house.glb` を置くと、トップページのヒーローと3Dシミュレーターで
「サンプルの3Dハウス」として表示されます。ファイルが無いときは、これまでどおり
入力した寸法から組み立てたハウスが表示されます(見積りの数量計算はどちらでも変わりません)。

## Blender からの書き出し方

1. `ファイル > エクスポート > glTF 2.0 (.glb/.gltf)`
2. 形式: **glTF Binary (.glb)** … テクスチャも1ファイルにまとまります
3. 「含める」: 選択したオブジェクトのみ(必要なら) / **カスタムプロパティは不要**
4. 「データ」: **モディファイアーを適用** にチェック
5. 「圧縮」: Draco圧縮は**使わない**(使う場合は連絡してください。デコーダを別途同梱します)
6. ファイル名は `house.glb`

## 気をつけること

- **実寸(メートル)で作ってください。** 間口6m・奥行24mのハウスなら、Blender上でもその寸法に。
  原寸が違う場合は `assets/config.js` の `sampleModelWidth` に間口(m)を入れると合わせます。
- **Z-up ではなく Y-up** で書き出されます(glTFの仕様どおりで問題ありません)。
- 地面は入れなくて大丈夫です。こちらで地面と影を付けます。底面が y=0 に来るよう自動で置きます。
- **ファイルサイズは20MBくらいまで。** スマホでも開くので、テクスチャは2048px以下、
  面数は100万ポリゴン以下を目安にしてください。重いときは連絡してください。減らします。
