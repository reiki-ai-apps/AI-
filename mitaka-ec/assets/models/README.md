# サンプルの3Dハウス

Blender などから書き出した `.glb` をこのフォルダに置き、`assets/config.js` の
`sampleModels` に並べると、トップページのヒーローと3Dシミュレーターに出ます。
**何棟でも並べられます。** シミュレーターでは「入力した寸法 / 単棟ハウス / 連棟ハウス …」と
ボタンで切り替えられ、トップのヒーローには1棟目が出ます。

```js
// assets/config.js
sampleModels: [
  { label: "単棟ハウス", file: "assets/models/house-a.glb", width: 0 },
  { label: "連棟ハウス", file: "assets/models/house-b.glb", width: 0 },
],
```

`label` は画面に出す名前、`width` は間口(m)。実寸で書き出していれば `0` のままで結構です。
`sampleModels` が空のときは読みに行かず、これまでどおり入力した寸法から組み立てたハウスを表示します。
**見積りの数量計算は、サンプルを表示していても入力した寸法で行います。**

## Blender からの書き出し方

1. `ファイル > エクスポート > glTF 2.0 (.glb/.gltf)`
2. 形式: **glTF Binary (.glb)** … テクスチャも1ファイルにまとまります
3. 「データ」: **モディファイアーを適用** にチェック
4. 「圧縮」: Draco圧縮は**使わない**(使う場合は連絡してください。デコーダを同梱します)
5. 1棟ずつ別々のファイルに書き出してください

## 気をつけること

- **実寸(メートル)で作ってください。** 間口6m・奥行24mのハウスなら、Blender上でもその寸法に。
  原寸が違う場合は `width` に間口(m)を入れると合わせます。
- 地面は入れなくて大丈夫です。こちらで地面と影を付けます。**底面が y=0 に来るよう自動で置き、
  平面の中心も自動でそろえます。**
- **1ファイル20MBくらいまで。** スマホでも開くので、テクスチャは2048px以下、
  面数は100万ポリゴン以下を目安に。重いときは連絡してください。減らします。
- 外観・正面(妻面)・横・上から・内観の画角は、モデルの大きさに合わせて自動で合わせます。
