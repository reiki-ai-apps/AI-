# 前回の発信者を繰り返さない動画選定（2026-09-17）

- 毎朝、投稿10日以内・未掲載の動画から2件。別動画でも、前回の最終掲載回の発信者は候補から除外する。
- 「前回」は日本時間で今日より前の最新の掲載回。更新が途切れた日があってもリセットしない。
- 同じ枠内も2人以上の別発信者。識別済みの共演者も含めて重複を防ぐ。
- 前回の発信者の一覧をその日の間は固定する。1件だけ先に掲載できた場合、再試行はその1件を残して別人を追加する。
- 2件そろった後は同日の再試行で入れ替えない。旧方式で前回の人を掲載してしまった状態だけは修復する。
- 審査前・新着選定・日次更新の完了判定に前回人物の除外ルールを適用。
- 2026-09-19の「動画の記事はいつも2つ」の指示により、表示件数と新着完了数を分離。新着が不足する間は10日以内の審査済み動画で2枠を維持し、「継続掲載」を明示する。前回と違う発信者の補充候補を優先し、足りない場合のみ前回分を残す。同じ枠内の人物・共演者・動画・論点の重複禁止は維持。
- 新着2件未満は未完了として既存の自動再試行へ。継続動画で成功日・元投稿日・新着数を偽装しない。フロントの予備候補はサーバーが審査済みとして明示したものに限る。
- 検証による除外後にも2枠を再確定。期限内の有効な組み合わせ自体がない場合は、1件版を公開して既存版を上書きせず公開を保留する。公開10日以内の条件は緩和しない。
- 過去30日分の最終掲載回を保存。従来の履歴はその日の最後の異なる2人から移行する。

通常記事のトップ5、アクセス集計、会員制度の廃止、記事本文の読みやすさに関する設定は変更しない。
