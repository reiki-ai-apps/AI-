### 曲の核（映像が語るべきこと）

- 主人公は昼休みのオフィスにいる「私」。やることリスト、コピー機の音、冷めたコーヒー、ミスしたメール。
- 行動は「折りたたんで飛ばす」。ため息もミスも退屈も紙飛行機にして窓の外へ出す。小さな反抗。
- 宣言は「金の冠はいらない。紙の羽で風はつかめる。少し曲がった線の方が遠くへ飛べる」。
- ジャケットは「夜のネオン都市」だが歌詞は「昼のオフィス」。この2つをつなぐのが映像の仕事。
  答えは「昼の街をネオン色で塗る」＝ サビの "fireworks in daylight"。

## 2. 映像コンセプト 3案

### A案「12:00、机の上から離陸」（歌詞＝物語型）★推し

- 舞台: 実在感のあるオフィスの机。付箋、やることリスト、コピー機、冷めたコーヒー、赤ペン。
- 仕掛け: 歌詞テロップを「付箋・メモ紙に書かれた文字」として出す。節が進むたびに紙が折られ、
  紙飛行機になって画面外へ飛ぶ。サビで視点が「机 → 窓 → 街の上空」へ抜け、ジャケットの世界になる。
- 色: 昼のオフィスはクリーム／白／グレー＋蛍光ペン1色（ピンク）。サビはジャケットのネオン（ピンク／紫／シアン）。
- 人物: 顔を出さない主観視点（手・机・窓だけ）。人物画像なしで今すぐ始められる。
- 文字: 太めゴシック（`--font-style gothic`）。

### B案「紙でできた街」（世界観型）

- 全部が紙。ペーパークラフトのビル、折り紙の雲、切り絵の光。紙飛行機が主役キャラ。
- 質感を固定（紙の繊維、切り口の影）。画像生成のプロンプト例:
  `paper craft diorama, cut paper city at noon, cream paper, neon pink and cyan light leaks, soft shadows, vertical 9:16`
- 歌詞は紙ラベル風。影ぼう型の「絵柄で覚えてもらう」路線。

### C案「kikitoa というキャラ」（ペルソナ固定型）

- 会社員の女の子を1人決める（カーディガン、社員証、胸に紙飛行機のピン）。全曲この子。
- 表情差分5枚（頬杖・ため息・笑う・投げる・見上げる）を歌詞の節に当てる。
- 次の曲以降も同じ子で出し、チャンネルの顔にする。Benny Rivers 型。

### 推奨

**A案を土台に、C案の「固定した手と持ち物」を混ぜる。** 理由は3つ。

1. 歌詞が具体的（頬杖・コピー機・コーヒー・メール）で、画にした瞬間に「読める」。
2. 静止画でも「紙が折られて飛ぶ」の連続で動きが出る。前回の「1枚が動かない」を脱せる。
3. 素材が今すぐ揃う。人物画像は不要、背景6〜8枚とジャケットの作り直しだけで着手できる。

B案は2曲目以降の「世界観の拡張」に、C案は3曲たまった時点でキャラを立てる用に取っておく。

## 5. 用意する素材と設定

- ジャケット: 今の 360px は小さい。同じ構図で 1080px 以上に作り直す。
- 背景画像 6〜8枚（縦 1080×1920）: 机の上 ／ コピー機 ／ 窓と昼の街 ／ 紙の王冠 ／ カレンダー ／ 昼の空と花火 ／ 雲の上 ／ 手と紙飛行機。
  実写風かイラストか、どちらか1つに固定する。
- 人物画像: 任意。手だけ、または後ろ姿。
- パイプライン設定:

```bash
python make_frames.py --jacket jacket_1080.png --title "PAPER PLANE ROYALTY" --artist kikitoa \
  --lyrics lyrics_final_chorus.txt --font-style gothic --lines-per-frame 2 --style auto \
  --person bg_desk.png --person bg_window.png --person bg_crown.png --person bg_sky.png --out frames/
python build_video.py --manifest frames/frames.json --audio PAPER_PLANE_ROYALTY.mp3 \
  --audio-start 97.6 --duration 52 --transition fade --loudnorm --out ppr_short.mp4
```

## 6. 投稿の勝ち筋（お手本6本から）

- 歌詞テロップが主役。2行ずつ、太めゴシック、画面中央。
- 音源を TikTok に「PAPER PLANE ROYALTY - kikitoa」として登録し、"Fold it, flip it" の8秒を推奨区間にする。
- キャプション案: 「昼休みに、やることリストを紙飛行機にした曲」。プロフィールと概要欄に Suno 使用を明記。
- シリーズ化: 「オフィスの小さな反抗」として次の曲も同じ机・同じ手・同じ書体で出す。

## 7. できなかったこと

- 音声の聴取はできないため、セクションの秒数は音量曲線と歌詞の行数からの推定。投稿前に耳で合わせる。
- 歌詞の自動文字起こし（Whisper）はモデル配布元がこの環境から遮断されており不可。歌詞はタグ埋め込み分を使用。

プレビューで分かったこと:

- 歌詞テロップ（太めゴシック、2行）はネオン背景でも読める。書体の選択はこのままでよい。
- 背景がジャケット1枚のぼかしだけなので、52秒間ずっと同じ紫の画面になる。ここに第4章の背景6〜8枚を入れるのが次の作業。
- 歌詞の切り替えはフレーム数で等分される。ボーカルと完全には同期しないので、投稿前に `--audio-start` を耳で ±1秒調整する。

### スキルの不具合と修正（`docs/patches/`）

- `make_frames.py` の `fit_text` が、文字が領域に収まらないときサイズを下げずに `while True` を回り続け、無限ループになる。
  IPA ゴシックで「PAPER PLANE ROYALTY」を表紙に置くとこの条件に当たり、処理が止まった。
- 折り返しが日本語向けの1文字単位のため、英語タイトルが「ROYAL / TY」と単語の途中で割れる。半角スペースを含む行は単語単位で折り返すようにした。
- 修正差分: `docs/patches/make_frames-text-fit-fix.patch`（スキル側の `scripts/make_frames.py` に適用する）。
- `build_video.py` は `ffprobe` を必要とするが、この実行環境には無かった。`ffmpeg -i` の出力を JSON 化する代替を
  `docs/patches/ffprobe-shim.py` に置いた（`ffprobe` という名前で PATH に置けば動く）。本物の ffprobe がある環境では不要。
