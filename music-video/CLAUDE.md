# music-video/ の決まりごと

kikitoa（Suno で作った AI 音楽）の TikTok / YouTube Shorts 用ミュージックビデオ。

## 絶対に守ること

- **Suno の自動生成ジャケットは使わない。**
- **音源は再エンコードしない。** ffmpeg では必ず `-c:a copy`。元は 320kbps。
- **字幕は英語 + 日本語訳**、ボーカルに合わせる。`lyrics_timing.json` が正。
- 動画は縦 **1080x1920 / 30fps**。
- コミット・PR・コード内に、使ったモデル名を書かない。

## キャラクターと世界観

`kikitoa/WORLD.md` が正。要点だけ:

- 主役は **C**（20歳前後、濃紺の短髪に琥珀のメッシュ、紺のロングコート、首にヘッドホン）
- 色は **濃い藍 / 琥珀 / 白 の 3 色のみ**。夜は藍、朝は琥珀
- 場所は屋上。空が広く地平線が低い
- 曲ごとに別の物語を作らない。同じキキがその日どう思っているかだけ変える

## 組み立て

```bash
cd kikitoa/nym
python3 prep_layers.py     # プレート1枚をレイヤーに分解 → art/
python3 build_shots.py     # カット割りから shots.json を生成
python3 ../../common/compose.py --spec shots.json --song <mp3> --out out.mp4
```

- **`shots.json` は直接編集しない。** `build_shots.py` の `CUTS` と `FRAMING` を直して再生成する。
- `art/` は中間ファイル。コミットしない。
- 静止画で確認するときは `--stills 191,197.5,206 --out-dir stills/`（**絶対秒**で指定）。
- 拍の解析は遅いので `--grid-json grid.json` でキャッシュする。

## 生成するとき

`kikitoa/PIPELINE.md` に何が効いて何が駄目だったかが全部書いてある。特に:

- `soul_cinematic`（0.12/枚）で足りる。`flux_kontext`（1.5）は要らない
- プロンプトの頭で「これは絵である」と宣言する。写真を否定するだけでは足りない
- **画像参照は構図ごとコピーする。** 場面を変えたいカットに前のカットを渡さない
- 生成したら見る前に平均輝度を測って弾く（夜明けの風景 90〜130、顔 110〜150）
- 動画生成は 5 秒 7.5〜32.5 クレジット。画像の 62〜270 倍。枚数で作るほうが桁で安い

## この絵で分かっていること

- **全レイヤー `depth: 0`。** 空と地面しかなく手前に置くものが無いので、視差は効かない
- 人物を別レイヤーにするのは `sway`（風で揺らす）ためであって、視差のためではない
- 脚は切り出さない。背景に残す。足は地面に着いていて揺れない
- 背景から人物を消すときは輪郭をなぞらず**矩形で**消す
