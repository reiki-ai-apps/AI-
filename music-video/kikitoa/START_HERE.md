## これは何か

**kikitoa**（Suno で作った AI 音楽）の TikTok / YouTube Shorts 用ミュージックビデオ。
1年以上投稿して結果ゼロだった。原因は、静止画1枚に歌詞も無く、見る価値が無かったから。

曲は2曲:

| 曲 | 内容 | 状態 |
|---|---|---|
| NOT YOUR MEDICINE | 「僕は君の薬じゃない」。境界を引く歌。夜→朝 | **14カットで50秒組み上がり済み** |
| PAPER PLANE ROYALTY | 「私は紙飛行機の女王」。明るい。昼 | 未着手 |

## 決まっていること（勝手に変えない）

### 主役は C

20歳前後の女性。**曲の登場人物ではなく、歌っている本人。**
曲ごとに別の物語を作らない。同じ C が、その日どう思っているかだけが変わる。

| | |
|---|---|
| 顔 | 面長、顎と頬骨を出す。丸顔・童顔にしない |
| 目 | 細いアーモンド形、視線は水平で遠い。冷たい琥珀色 |
| 髪 | 濃紺（ほぼ黒）の短髪、耳の高さ、少し乱れる。**右のこめかみに琥珀のメッシュ一房** |
| 服 | 紺のロングコート（ふくらはぎ丈、襟を立て前は開ける）、白シャツ、黒の細いパンツ、黒の革ショートブーツ |
| 小物 | **黒の大きいオーバーイヤーヘッドホンを首にかける** |

**識別記号は3つだけ**（これが「kikitoa の顔」）:
琥珀のメッシュ／首のヘッドホン／濃紺・琥珀・白の3色。

引きで効くのは**コートのシルエット**、寄りで効くのは**メッシュとヘッドホン**。
役割が分かれているので「引き＝コート、寄り＝メッシュとヘッドホン」で撮り分ける。

### 色は3色だけ

濃い藍 / 琥珀 / 白。**夜は藍、朝は琥珀。** 全曲これで通す。

### 場所

屋上。空が広く地平線が低い。電線が横切る。遠くに街の影。C は基本的に一人。
参考は影ぼう「開拓者」。

### 毎回の型

1. 冒頭3秒 顔のアップ（目だけ）。ここで誰の動画か決まる
2. Aメロ 引きの画。屋上に小さく立つ
3. サビ **琥珀の線**が画面を横切り、歌詞がその上に乗る
4. 終わり 線が残ったまま終わる ← 毎回ここで終える。スクショされる画になる

### 「線」は勝手な比喩ではない

NOT YOUR MEDICINE に「線を引いて」、PAPER PLANE ROYALTY に
「少し曲がった線でいい / その方が遠くへ飛べる」。**両方の歌詞に実際に出てくる言葉。**
だからチャンネルの背骨にできる。曲がった線はコードで生成済み（費用ゼロ）。

### 絶対に守ること

- **Suno の自動生成ジャケットは使わない**
- **音源は再エンコードしない。** ffmpeg で必ず `-c:a copy`。元は 320kbps
- **字幕は英語＋日本語訳**、ボーカルに合わせる
- 縦 1080x1920 / 30fps
- コミット・PR・コードに使ったモデル名を書かない

### 1. 絵を増やす ← これが一番効く

14カットに増やしても、**絵が1枚では「同じ絵の切り取り違い」**にしかならない。
動いて見えるかどうかは枚数で決まる。

何が要るかは **`SHOT_LIST.md` に発注書**（プロンプト付き）がある。
NOT YOUR MEDICINE に9枚、PAPER PLANE ROYALTY に3枚、予備込みで**16枚・約2クレジット**。

### 2. 顔のアップの前に Soul を学習させる

外見をテキストで書くだけでは顔が毎回ずれる。同じ顔で揃えるには
`show_characters action='train'`（同じキャラの参照画像5〜20枚、約10分）。
学習済みは `soul_cinematic` で使える。

**順番**: 先に引きとシルエット（顔が小さいカット）を出す → 学習 → 顔のアップ。

## 動かし方

```bash
pip install -r music-video/requirements.txt   # 別途 ffmpeg も要る
# 音源を music-video/audio/ に置く（リポジトリには入っていない）

cd music-video/kikitoa/nym
python3 prep_layers.py     # プレート1枚をレイヤーに分解 → art/
python3 build_shots.py     # カット割りから shots.json を生成
python3 ../../common/compose.py --spec shots.json \
        --song ../../audio/NOT_YOUR_MEDICINE.mp3 --out nym.mp4
```

- **`shots.json` は直接編集しない。** `build_shots.py` の `CUTS`（いつ・どの framing）と
  `FRAMING`（プレートのどこを切り取るか）を直して再生成する
- 静止画で確認: `--stills 191,197.5,206 --out-dir stills/`（**絶対秒**で指定）
- 拍の解析は遅い。`--grid-json grid.json` でキャッシュする

## 作業中に分かったこと（高くついたので消さない）

### 生成の値段

| | 単価 | 50秒ぶん |
|---|---|---|
| **画像を増やしてカットで見せる** | **0.12 / 枚** | 14枚で **1.7** |
| `kling3_0` / `grok_video` | 7.5 / 5秒 | **75** |
| `seedance_2_5` | 32.5 / 5秒 | **325** |

**動画生成は画像の62〜270倍。** 動画の強みは「生成した動画」ではなく
**枚数を増やして速く切ること**で出すほうが桁で安い。

### 生成のコツ

- `soul_cinematic`（0.12）だけで足りる。`flux_kontext`（1.5）は**要らない**
  （「Higgsfield はアニメを直接出せない」と一度結論を出したが、あれは背景美術だけの話で、
  人物と人物のいる風景には当てはまらなかった）
- プロンプトの**頭で「これは絵である」と宣言する**。写真を否定するだけでは足りない
  → `A vertical hand-painted 2D anime key visual ..., cel painting on paper,
  absolutely not a photograph and not a 3D render.`
- **画像参照は構図ごとコピーする。** キャラシートを参照して「同じ子を屋上に」と書いたら、
  屋上ではなくシートのレイアウトが複製された。場面を変えたいカットに前のカットを渡さない。
  外見はテキストで書き直すほうが通る
- 生成したら**見る前に平均輝度を測って弾く**
  `identify -format "mean=%[fx:int(mean*255)]"` → 夜明けの風景 90〜130、顔 110〜150。
  暗さを書くと潰れる。**光源の方を書く**
- 無料枠は**同時1ジョブ**。並べて投げると2本目が落ちる

### 組み立てのコツ

- **全レイヤー `depth: 0`。** 空と地面しかなく手前に置くものが無いので視差は効かない。
  `depth` を変えると切り出したコートと背景に残した脚が離れる
- 人物を別レイヤーにするのは **`sway`（風で揺らす）ため**であって、視差のためではない
- **脚は切り出さない。** 細くてマスクが塊になるうえ、足は地面に着いていて揺れない
- 背景から人物を消すときは**輪郭をなぞらず矩形で消す**。輪郭に沿うとブーツの外側などが必ず残る
- 埋め戻しは行ごとの中央値 → その領域を広くぼかす。
  「同じ行の離れた場所から借りる」方式は元画像から本人を拾って**失敗した**
