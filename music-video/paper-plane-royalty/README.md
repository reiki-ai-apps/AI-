# PAPER PLANE ROYALTY「折って、飛ばす。」アニマティック

演出プラン（`docs/paper-plane-royalty-visual-concept.md`）を、実写・AI生成素材が無い段階で
動画として確認するためのプレビズ。全部プログラム描画で、実際の音源の拍に同期している。
Suno 自動生成ジャケットは使っていない。

## 何が入っているか

| ファイル | 内容 |
|---|---|
| `animatic.py` | 生成スクリプト。拍解析 → 紙の折り工程（幾何計算）→ 各シーン描画 → ffmpeg で MP4 |
| `storyboard.jpg` | 完成動画から各シーンを抜いた絵コンテ |

## 動画の構成（音源 1:12.6 から 41秒、136 BPM）

| 拍 | 秒 | シーン | 画面 |
|---|---|---|---|
| 0–3 | 0.0–1.8 | フック | 灰色の机、白い始末書、手が伸ばす。テロップ「始末書、紙飛行機にしてみた。」 |
| 4–15 | 1.8–7.1 | 折り | 2拍に1折り×5。折るたびに裏面に手書きの歌詞（Fold it, / flip it / Send it to / the ceiling / Catch it, kiss it） |
| 16–19 | 7.1–8.8 | 掲げる | 横アングル。蛍光灯が拍でチラつき、先端だけピンクに光る。翼に「Small wings」 |
| 20–23 | 8.8–10.6 | 発射 | 上昇。天井タイルが紙のようにめくれて空（最初の色）。最後の拍で黒 |
| 24–39 | 10.6–17.7 | ブリッジ前半 | 窓越しの灰色の街を滑空。「正解ばかり探してたら」「笑い方まで固くなる」 |
| 40–55 | 17.7–24.8 | ブリッジ後半 | 折り目のマクロ（ピンクの点線＝少し曲がった線）→ ビルの横を傾いて抜ける |
| 56–59 | 24.8–26.6 | 一呼吸 | 灰色の空に小さな飛行機 |
| 60–67 | 26.6–30.2 | 最終サビ | 1拍目で世界に色。窓から無数の紙飛行機 |
| 68–75 | 30.2–33.7 | 花火 | 昼の空にパステルの花火。「bright」で白フラッシュ＋彩度 |
| 76–83 | 33.7–37.2 | 王冠 | 色のついた机。紙の王冠を手が脇へ押しのける |
| 84–87 | 37.2–39.0 | 飛来 | 飛行機がカメラへ向かって拡大 |
| 88–91 | 39.0–41.0 | 着地・ループ | 机に着地。色が灰色に戻り、逆再生で開いて始末書に戻る＝1コマ目と同じ画 |

## 作り方

```bash
pip install numpy librosa soundfile pillow imageio-ffmpeg
python3 animatic.py --song PAPER_PLANE_ROYALTY.mp3 --out animatic.mp4
python3 animatic.py --song PAPER_PLANE_ROYALTY.mp3 --stills 0.2,3.5,8.5 --out-dir stills/  # 静止画で確認
```

`ffmpeg` と `ffprobe` が PATH に必要。`ffprobe` が無い環境は `docs/patches/ffprobe-shim.py` を使う。

## これは何であって何でないか

- これは「カット割り・拍同期・色のルール・歌詞の出し方・ループ」の確認用。絵の質は本番ではない。
- 本番は、机のパートをスマホで実写、空・街・無数の飛行機を AI 生成（静止画→動画化）で作る。
  シーンの尺と切り替え位置はこのアニマティックのままでよい。
- 拍位置は音源解析で決めているが、歌い出しとの完全一致は耳で確認していない（この環境では音を聴けない）。
