# 予約状況の同期契約

POST BOARDの最優先目的は、Asia/Tokyo の今日を起点に「今日・明日・2日後」の予約がすべて完了しているかを、投稿単位で示すことです。

- 投稿名・媒体・予定時刻・承認状態の正本は`board.json`の`channelPosts / postGroups / publicationPackages`とする。
- 表示日は端末の今日から動的に計算し、今日・明日・2日後の3日を日付順に出す。`status.json`の古い日付を表示基準にしない。
- `SCHEDULED / PUBLISHING`だけを予約済みとする。`PENDING_APPROVAL`だけを承認待ちとする。
- 品質ゲートがPASSしていても、まだ`PENDING_APPROVAL`へ送られていない投稿は「承認準備済み」とし、承認待ちと混同しない。
- 下書き・制作中・要対応は未予約とし、投稿自体が登録されていない日は「投稿未登録」とする。
- 3日のうち1投稿でも未予約・承認待ち、または1日でも投稿未登録なら全体を危険とする。推測で予約済みにしない。
- AI進化レーダーはPOST BOARDの予約監視対象に含めない。
- 予約日時、対象媒体、投稿ID、承認証跡または予約receiptが変わった場合は、その実行で再計算する。

公開済み件数や制作状況は補助情報です。予約不足より上位の正常判定には使用しません。
