# AI進化レーダー（毎日自動更新版）

AIに関する重要ニュースを **3時間ごとに自動で確認して表示** するダッシュボードです。

## 仕組み（むずかしくないので安心してください）

1. GitHub が **3時間ごと** に `update.js` を自動実行
2. `update.js` がAIニュースを収集し、AIで日本語要約・重要度・分野を判定して `data.json` を更新
3. GitHub Pages が変更を検知して **サイトを自動で再公開**
4. アプリ（`index.html`）は開くたびに `data.json` を読むので、いつ開いても最新

→ 一度セットアップすれば、あとは **何も操作しなくても毎日勝手に更新** されます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（これがサイトとして表示される） |
| `data.json` | 公開する要約済み最新ニュース（最大60件） |
| `update.js` | ニュースを集めて data.json を作るスクリプト（GitHubが実行） |
| `.ai-cache.json` | 同じ記事をAIで何度も処理しないための履歴（自動生成） |
| `.ai-usage.json` | 日別のAPI呼出数・トークン数・処理件数（自動生成） |
| `.github/workflows/update.yml` | 3時間ごとの監視・検証・公開設定 |

## セットアップ手順

詳しい手順は、チャットでClaudeが案内します。大まかには：

1. GitHub（無料）にこのフォルダ一式をアップロードして公開リポジトリにする
2. GitHub の **Settings → Pages** で GitHub Pages を有効にする
3. GitHub の **Actions** タブで `Update AI feeds` を一度手動実行（Run workflow）
4. 完了。以後は3時間ごとに自動で確認・更新・公開されます

## AI利用量の安全設定

- 1回の実行は最大12記事です。政策・安全性・中国/世界の新モデル・半導体を先に1件ずつ確保します。
- 通常は1日40記事まで、重要分野のみ追加8記事まで処理できます。
- 採用済みは31日、不採用は7日記録し、同じ内容への重複課金を防ぎます。
- `.ai-usage.json` とGitHub ActionsのSummaryで、実際の入力・出力トークン数を確認できます。
- 金額換算を使う場合は、GitHub Actions Variablesに利用モデルの最新単価を設定します。単価未設定時は推測金額を表示せず、実トークン数だけを記録します。

## 取得対象を増やす・変える

`update.js` の先頭の `TOOLS` リストに、ツール名とフィードURLを足すだけです。
迷ったら Claude に「このツールを追加して」と頼んでください。
